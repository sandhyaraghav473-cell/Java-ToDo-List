# Java-ToDo-List
A simple console-based To-Do List application developed in Java using ArrayList and Scanner.
Java To-Do List

A simple console-based To-Do List application developed using Java. This project allows users to manage their daily tasks through a simple menu-driven interface.

Project Overview

The Java To-Do List is a beginner-friendly console application that helps users add, view, update, and delete tasks.

The main purpose of this project is to understand the basic concepts of Java programming and how data can be stored and managed using an "ArrayList".

Features

- Add a new task
- View all tasks
- Update a task
- Delete a task
- Menu-driven console interface
- Simple and easy-to-use program

Technologies Used

- Java
- Java "ArrayList"
- Java "Scanner"

Java Concepts Used

1. ArrayList

"ArrayList" is used to store the list of tasks dynamically. Unlike a normal array, an ArrayList can grow or shrink as tasks are added or removed.

2. Scanner

"Scanner" is used to take input from the user through the keyboard.

3. Loops

Loops are used to repeatedly display the menu and allow the user to perform multiple operations without restarting the program.

4. Conditional Statements

"if-else" and/or "switch" statements are used to perform different operations based on the user's choice.

5. Methods

Methods are used to divide the program into smaller and easier-to-understand sections.

6. CRUD Operations

The project demonstrates basic CRUD operations:

- Create – Add a new task
- Read – View tasks
- Update – Modify an existing task
- Delete – Remove a task

How to Run

Step 1: Install Java

Make sure Java JDK is installed on your computer.

Step 2: Clone the Repository

Clone this repository using Git:

git clone https://github.com/YOUR-USERNAME/Java-ToDo-List.git

Step 3: Open the Project

Open the project folder in VS Code, IntelliJ IDEA, or another Java IDE.

Step 4: Compile the Program

Open the terminal and run:

javac TodoList.java

Step 5: Run the Program

java TodoList

Sample Output

The program displays a menu similar to:

===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Exit

The user can select an option and manage their tasks.
